# Job Application Tracker

A web application that helps users manage and track job applications efficiently.

## Features

* Add job applications
* Edit application details
* Delete applications
* Status filtering
* Local storage persistence
* Responsive user interface

## Technologies Used

* HTML5
* CSS3
* JavaScript
* LocalStorage

## Future Enhancements

* Search functionality
* Dashboard analytics
* Dark mode
* Application date tracking
